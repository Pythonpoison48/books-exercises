* Exercise 4/5:

You can use scp or rsync . Be careful that scp
- doesn't save attributes (permission,dates/time stamp, etc...)
- lose symbolic links
- Always copy files even when unnecessary
#+begin_src shell

# with scp
scp -r <user>@<ip_address>:/usr/share/help/es /tmp/

# with rsync

rsync -avl <user>@<ip_address>:/usr/share/help/es /tmp/

#+end_src

** scp args
-r for recursive

** rsync args
-a for recursive
-v for verbose
-l for symbolic links

* Exercise 6
To create our ssh key we use =ssh-keygen=

#+begin_src shell

ssh-keygen

#+end_src

Then we use =ssh-copy-id= , type the password .

#+begin_src shell

ssh-copy-id -i ~/.ssh/key_linux_bible.pub <user>@<ip_address>

#+end_src

then we connect and voila !

#+begin_src shell

ssh -i ~/.ssh/key_linux_bible.pub <user>@<ip_address>
#+end_src
