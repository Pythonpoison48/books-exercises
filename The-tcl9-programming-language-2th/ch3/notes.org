* Comments quirk

In tcl you need to match braces ({}) in comments because
Tcl checks for comments after parsing the command into words but before
substitutions
#+begin_src tcl

proc demo {n} {
    # exemple comment with { character
    return $n
}
demo
#+end_src
When parsing the above script into words, Tcl encounters the left brace
character. At that point, it will look for the matching closing brace, even across
line boundaries. Not finding one will lead to the error.

* Renaming

To rename a command we can use =rename= like this.
#+begin_src tcl

rename OLDNAME NEWNAME

#+end_src
We can use rename to wrap commands to add new functionalities
we can even rename builtin commands (*strongly advised against doing so*)

** Renaming puts

#+begin_src tcl
rename puts builtin_puts

proc puts args {
    set str [string toupper [lindex $args end]]
    builtin_puts {*}[lreplace $args end end $str]
}

puts "hello world!"
#+end_src

** One time initalisation in commands

If one of our commands require to do an action only once
for example a log function that logs output to a file if debug_mode
is on. Two problem/annoyance :
- We need to check if debug_mode is on or off every call
- We need to specify the log file every call

Those are not big problems but it's repetitive
and error prone

We could use a default parameter or global variables , or
One other way would be to redefine our procedure in the procedure itself
with string interpolation as =proc= is just another command in tcl.
using =tailcall= command explained in chapter =14.1.7=

#+begin_src tcl

set debug_mode 0
set debug_file "myfile.txt"


# our log procedure
proc log {text debug_mode debug_file} {
    if { $debug_mode == 1 } {
        # if we are debugging
        puts "debug mode on logging start"
        # we use string interpolation to create a
        # logging procedure redifining log
        # which will output text to the file we assigned to it on the first
        # call
        proc log {text} "
            set fp [open $debug_file w+]
            puts \$fp \$text
        "
        tailcall log $text

    } else {
        puts "debug mode off doing nothing"
        # if we are not in debug mode
        # log does nothing
        # we still take the same number of args
        # or else the program would fail
        proc log {text} {
            return
        }
        tailcall log $text
    }
}

# our initial call
log "My log" $debug_mode $debug_file

log "Test"

log "1 2 3"

#+end_src

* Defining procedure using proc

=proc= is just another command in tcl.

#+begin_src tcl
proc Name PARAMS BODY
#+end_src

We saw how to create named commands and redefine them
Now lets see how we can create commands

#+begin_src tcl
proc make_logger {logname} {

    proc logto$logname text "
        set fp [open $logname w+]
        puts \$fp \$text
    "

}

make_logger test_logger

logtotest_logger "my original text"
logtotest_logger "\n \n and another ! "
#+end_src

** Parameter options

*** Default parameter:

we can specify default value for our parameters
#+begin_src tcl

proc log {text {level "INFO"}} {
    puts "$level: $text"
}

#+end_src
